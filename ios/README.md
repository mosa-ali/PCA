# PCA iOS foundation

This is an intentionally inert SwiftUI launch shell. It contains no parental-control enforcement, monitoring, location, camera, microphone, device-activity, FamilyControls, ManagedSettings, or other restricted capability.

## Open and validate

Open `PCA.xcodeproj` in Xcode on macOS, select the `PCA` scheme, and run its unit tests. Xcode and the iOS SDK are not available in this Windows workspace, so no iOS build or test result is claimed here.

## Scope boundary

This foundation is not implementation authorization. Product capabilities must be introduced only after their platform authority, entitlement requirements, privacy design, and acceptance criteria have been separately approved.
